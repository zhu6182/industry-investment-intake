# 产业投资进件系统 - 产品需求文档

## Overview
- **Summary**: 构建一套面向产业园区招商引资全流程的进件管理系统，覆盖从渠道专员发起企业进件、天眼查自动核名、中台审核、招商人员跟进拜访、到BI看板数据可视化的完整链路。系统通过中国地图可视化看板为招商团队和政府决策者提供实时的数据洞察，同时建立合伙人推荐激励体系。**系统需支持PC端和手机端双端操作，PC端侧重数据管理与大屏展示，手机端侧重外勤场景的快速操作。**
- **Purpose**: 解决当前产业投资进件过程中信息分散、审核低效、跟进不可追溯、数据无法量化分析的问题。实现进件流程标准化、企业数据结构化、招商跟进可追踪、区域数据可视化。
- **Target Users**: 渠道专员、渠道主管、招商人员、招商主管、中台运营、系统管理员、政府决策人员

## Goals
- 实现企业进件全流程在线化，减少线下纸质流转
- 通过天眼查API自动核名并拉取企业结构化信息，降低人工录入
- **企业分配时自动生成制式企业分析报告**，帮助招商人员快速了解目标企业
- 建立可追溯的招商跟进记录体系（拜访、跟进、照片）
- 提供中国地图BI看板，按区域展示招商数据
- 建立合伙人/推荐人排名激励体系，提升渠道活跃度
- 实现基于角色的数据权限隔离（个人、团队、区域）
- **支持手机端操作**，满足招商人员外勤拜访场景

## Non-Goals (Out of Scope)
- 不涉及企业工商注册或变更的实际办理
- 不提供园区物理空间管理（空置率、合同管理等）
- 不包含财务/税务申报功能
- 不包含企业融资对接或投资决策功能
- BI大屏为PC端专属（1920×1080及以上），手机端展示简化数据面板

## Background & Context
- 产业园区招商工作涉及大量企业线索收集、资质审核、后续跟进
- 当前各环节信息孤岛，缺乏统一平台串联
- 天眼查提供企业工商信息API，可作为进件核名和信息拉取的数据来源
- 中国地图可视化大屏是当前政企BI项目的常见形态
- 招商人员存在大量外勤场景，需要手机端随时查看企业资料、记录拜访

## Functional Requirements

### FR-1: 企业进件发起
- 渠道专员可通过企业名称查询是否已有在途跟进
- 若无人跟进，可发起新进件，填写企业名称
- 上传进件资料：申请表、公司介绍PPT、资料表、多张照片

### FR-2: 天眼查自动核名与信息拉取
- 对接天眼查API，根据企业名称进行核名
- 校验规则：企业状态正常（无在途执行）、成立时间 ≥ 2年
- 自动拉取：行业分类、企业基本信息、股东结构
- 核名不通过时给出具体原因，允许渠道专员修正后重新提交

### FR-3: 中台审核与报告生成
- 中台运营人员查看待审核进件列表
- 查看进件详情：企业信息、上传资料、天眼查返回数据
- 审核操作：通过 / 驳回（需填写驳回原因）
- **审核通过后，系统自动生成制式企业分析报告**
  - 报告内容：天眼查企业信息（基本信息、股东结构、行业分类、成立时间）+ 进件上传资料摘要
  - 上传文件智能解析（PPT取标题页和关键页文字、资料表提取关键字段）
  - 报告格式：PDF，可下载、可在线预览
- 审核通过后，可手动或按规则分配给指定招商人员
- 招商人员接收分配时，自动获取该企业的制式报告

### FR-4: 招商跟进与拜访记录
- 招商人员查看已分配的企业列表（手机端可查看）
- 记录跟进情况（跟进方式、跟进内容、时间）
- 记录拜访情况（拜访时间、拜访地点、拜访内容、多张照片上传）
- 填写关键数据：申请园区地区（精确到市）、申请入驻面积
- 可多次跟进/拜访，形成时间线
- **手机端支持**：快速记录、照片上传、查看制式报告（外勤场景）

### FR-5: 团队管理与数据查看
- 招商主管可查看自己管理的团队所有招商人员的跟进/拜访记录
- 渠道主管可查看自己团队的进件情况
- 支持按区域、时间、人员维度筛选查看

### FR-6: BI中国地图可视化看板
- 中国地图可视化，按省/市展示招商数据分布
- 展示指标：企业数量、申请入驻面积、跟进状态分布等
- 支持下钻：省 → 市
- 高大上的大屏风格设计
- 权限控制：招商人员仅能看到所属区域，招商主管可看团队区域，中台/管理员/政府人员可看全国
- 手机端展示简化版数据面板（不展示地图大屏，用图表和数字卡片）

### FR-7: 后台基础配置
- 系统管理员可添加/编辑可申请入驻的园区地区（省/市/园区三级结构）
- 管理用户账号与角色分配
- 管理推荐人/合伙人体系配置

### FR-8: 合伙人/推荐人激励体系
- 渠道专员、渠道主管可作为推荐人、邀请人、合伙人
- 可查看自己推荐/邀请的企业数据
- 可查看推荐企业的申请入驻面积
- 排名系统：按推荐企业数、按申请入驻面积等维度排名

### FR-9: 企业跟进状态流转
- 清晰的状态机：待审核 → 审核通过 → 已分配 → 跟进中 → 已落地 / 已流失
- 任意状态变更有记录，支持审计追溯

### FR-10: 制式企业分析报告
- 触发时机：中台审核通过并分配企业给招商人员时
- 报告内容：
  - 封面（企业名称、生成时间、招商人员姓名）
  - 天眼查企业信息摘要（基本信息、行业分类、成立时间、股东结构）
  - 进件上传资料摘要（申请表关键字段、公司介绍PPT标题页/关键页文字、资料表关键数据）
  - 核名结果（是否通过、校验详情）
- 报告格式：PDF
- 功能：在线预览、下载PDF、手机端可查看

## Non-Functional Requirements

### NFR-1: 性能
- 进件提交接口响应时间 < 2秒（不含天眼查API调用）
- BI地图首屏加载时间 < 3秒
- 天眼查API调用超时设置为10秒，超时后提示用户稍后重试
- **制式报告生成时间 < 5秒**

### NFR-2: 安全
- 所有API接口需鉴权（JWT或Session）
- 文件上传需校验类型与大小限制
- 敏感数据（企业联系方式等）需脱敏展示
- 操作日志完整记录

### NFR-3: 可用性
- 支持主流PC浏览器（Chrome、Edge、Safari最新版本）
- **支持主流手机浏览器（iOS Safari、Android Chrome），响应式布局适配375px-428px宽度**
- 文件上传支持断点续传（大文件如PPT）
- 响应式布局，PC端适配1920×1080及以上大屏显示
- 手机端UI优化：底部导航栏、大按钮、简化表单

### NFR-4: 可扩展性
- 天眼查API调用层设计为可替换，方便后续切换数据源
- 角色权限采用RBAC模型，方便新增角色
- 报告模板设计为可配置，方便后续调整报告格式

### NFR-5: 测试保障
- **交付前所有功能必须经过完整测试，无已知Bug**
- 每个功能模块需包含单元测试和集成测试
- 关键业务流程需有端到端测试用例覆盖
- 手机端和PC端均需测试验证
- 测试覆盖率需达到核心路径100%

## Constraints

### Technical
- 前端：Vue 3 + TypeScript + Ant Design Vue（PC端） + Vant（手机端组件库），或采用 uni-app 一套代码两端运行
- BI大屏：ECharts（中国地图 + 丰富图表）
- 报告生成：PDF生成库（后端Node-PDF或前端html2pdf.js）
- 文件解析：PPT解析（pptxjs/python-pptx）、Excel解析（xlsx）
- 后端：Node.js (NestJS) 或 Java (Spring Boot)，待定
- 数据库：MySQL + Redis缓存
- 文件存储：对象存储（阿里云OSS / 腾讯云COS，根据部署环境）
- 天眼查API：需申请企业开发者账号并获取AppKey

### Business
- 天眼查API有调用配额限制，需设计合理的缓存策略
- 首期开发周期预计 8-10 周（含手机端适配和报告生成）
- 需与客户确认园区地区初始化数据

### Dependencies
- 天眼查开放平台API（企业信息查询）
- 对象存储服务（文件上传）
- 文件解析服务（PPT、Excel内容提取）
- PDF生成服务

## Assumptions
- 用户已具备天眼查企业开发者资质，可提供API密钥
- 首期部署环境为公网可访问的云服务器
- 园区地区初始化数据可由客户提供或由管理员在后台录入
- 合伙人/推荐人排名首期仅展示，暂不涉及结算打款功能
- 手机端首期通过响应式Web实现，不开发原生APP

## Acceptance Criteria

### AC-1: 企业进件发起
- **Given**: 渠道专员已登录系统（PC端或手机端）
- **When**: 输入企业名称查询，系统显示该企业无人跟进
- **Then**: 可发起新进件，填写企业名，上传申请表、PPT、资料表、多张照片后提交成功
- **Verification**: `programmatic`

### AC-2: 天眼查核名
- **Given**: 已提交进件
- **When**: 系统调用天眼查API
- **Then**: 自动获取企业状态、成立时间、行业分类、基本信息、股东结构；若企业状态异常或成立不足2年，给出明确提示
- **Verification**: `programmatic`
- **Notes**: 天眼查API实际返回字段需联调确认

### AC-3: 中台审核与自动分配
- **Given**: 进件已完成天眼查核名且通过
- **When**: 中台运营审核通过
- **Then**: 可将该企业分配给指定招商人员，招商人员端出现新待办
- **Verification**: `programmatic`

### AC-4: 制式企业分析报告生成
- **Given**: 中台审核通过并分配企业给招商人员
- **When**: 系统自动生成报告
- **Then**: 5秒内生成PDF报告，包含天眼查信息摘要+上传资料摘要，招商人员可在线预览和下载
- **Verification**: `programmatic`

### AC-5: 招商跟进与拜访记录
- **Given**: 招商人员已被分配企业
- **When**: 记录跟进情况或拜访情况
- **Then**: 保存成功，时间线可追溯，可上传多张照片，可填写申请园区地区（精确到市）和申请入驻面积
- **Verification**: `programmatic`

### AC-6: 团队数据可见性
- **Given**: 招商主管已登录
- **When**: 查看团队数据
- **Then**: 能看到自己管理的所有招商人员的跟进/拜访记录
- **Verification**: `programmatic`

### AC-7: BI中国地图看板
- **Given**: 用户已登录且有权限
- **When**: 访问BI看板（PC端）
- **Then**: 展示高大上风格的中国地图，按省/市展示企业分布，支持下钻，指标数据准确
- **Verification**: `human-judgment`
- **Notes**: "高大上"为审美判断，建议参考政企大屏风格

### AC-8: 招商人员区域权限
- **Given**: 招商人员归属某区域
- **When**: 访问BI看板或数据面板
- **Then**: 仅能看到所属区域的数据，无其他区域数据
- **Verification**: `programmatic`

### AC-9: 后台园区地区管理
- **Given**: 系统管理员已登录
- **When**: 在后台添加新的园区地区（省/市/园区）
- **Then**: 保存成功，后续进件可选择该地区
- **Verification**: `programmatic`

### AC-10: 合伙人/推荐人体系
- **Given**: 渠道专员已登录
- **When**: 查看自己推荐/邀请的企业
- **Then**: 能看到推荐的企业列表、申请入驻面积，以及排名
- **Verification**: `programmatic`

### AC-11: 文件上传
- **Given**: 用户正在进件或记录拜访
- **When**: 上传多张照片或大文件（PPT等）
- **Then**: 上传成功，支持批量上传，有进度提示
- **Verification**: `human-judgment`

### AC-12: 手机端适配
- **Given**: 招商人员/渠道专员在手机端访问系统
- **When**: 执行核心操作（查看企业列表、记录跟进/拜访、上传照片、查看制式报告）
- **Then**: 界面布局适配手机屏幕，操作流畅无明显错位，大按钮易点击
- **Verification**: `human-judgment`

### AC-13: 交付质量
- **Given**: 系统完成开发
- **When**: 进行全量功能测试
- **Then**: 所有功能正常运行，无已知Bug，PC端和手机端均通过测试
- **Verification**: `programmatic`
